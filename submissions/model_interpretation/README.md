# 발표 p8 「모델 해석」 설명

이 폴더의 그림 3장은 발표 자료 p8에 들어간 그림이다. 모든 숫자는 [`notebooks/20_model_interpretation.ipynb`](../../notebooks/20_model_interpretation.ipynb)를 실행하면 그대로 나온다 (실행 결과 저장된 상태로 커밋됨).

## 한 줄 요약

> p8은 **최종 제출 submit_38을 해석**한 페이지다. 다만 submit_38은 모델 하나가 아니라 순위를 섞은 결과라서, **아래 박스는 submit_38 파일을 직접 분해**했고, **①②③ 그림은 submit_38을 구성하는 HGB+로지스틱 모델을 대표로 다시 학습해 계산**했다. SHAP을 submit_38 전체에 직접 돌린 것은 아니다.

## 최종 제출의 구조와 해석 범위

```
submit_38 (LB 0.6707) = 0.5 × rank(submit_21) + 0.5 × rank(08-25 라벨 규칙)
                                   │                        └─ 규칙: 라벨=1 위로, 같은 라벨 안에서는 과거 중앙값 낮은 순 (투명해서 해석 불필요)
         submit_21 = 0.35 × s4 + 0.35 × s3 + 0.30 × s15   (셋 다 HGB + 로지스틱 순위평균)
                       │        │        └─ 09_shock_fix_final.ipynb, 다른 피처·보정 방식 → p8에서 해석하지 않음
                       │        └─ s2 모델 + 과거 기준선 보정(점수 사후 조정)
                       └─ s2와 같은 구조, 피처 31개 (s2의 42개에 모두 포함)
```

| p8 요소 | 무엇을 분석했나 | 최종 모델과의 관계 |
|---|---|---|
| 아래 박스 (51% · 127개) | **submit_38 제출 파일 자체** | 최종 제출 그대로 |
| ③의 121위 / 164위 / 83위 | submit_38 순위 / 08-25 규칙만의 순위 / submit_21 순위 | 최종 제출 그대로 |
| ① 그룹 중요도 · ② SHAP · ③ SHAP 막대 | **s2 구조 모델**(HGB 5시드 + 로지스틱, 피처 42개)을 `10_deflation.ipynb`와 같은 데이터·설정으로 다시 학습 | 최종 앙상블의 구성 모델. 다시 학습한 예측과 실제 제출 파일 s2의 순위상관 **0.994** |

최종 점수에서 비중으로 보면: 08-25 규칙 50% · s4+s3(= s2 구조) 35% · s15 15%. ①②③ 그림은 이 중 s2 구조 35% 부분을 대표한다.

## 그림별 설명

### ① 피처 그룹 중요도 — `fig1_group_importance.png`
- **어디서**: 백테스트 5개 기준일(08-01 ~ 08-05). 평가일보다 4일 이상 앞선 기준일로 학습.
- **어떻게**: 피처 42개를 6개 그룹으로 묶고, 그룹 전체를 섞었을 때 HGB+로지스틱 앙상블의 PR-AUC가 얼마나 떨어지는지 (그룹당 10회 반복). 하나씩 섞지 않은 이유: 08-25 라벨 관련 피처 19개처럼 서로 상관이 높으면 중요도를 나눠 가져 과소평가된다.
- **결과**: 08-25 라벨·역추론 0.227 ≫ 과거 수준 0.085 (약 2.7배) > 업로드 활동 0.036 > 최근 모멘텀 0.026 > 시청자 반응 0.023 > 게임 0.001

### ② SHAP 요약 — `fig2_shap_summary.png`
- **어디서**: 실제 9/1 테스트 694채널 예측 (학습쌍 5,102행 전체로 학습한 모델).
- **어떻게**: HGB에 `shap.TreeExplainer`(5개 시드 평균). 점 하나 = 채널 하나, 색 = 피처 값(진할수록 높음), 회색 = 결측(예: 「08-25 라벨=1 기준선 높이」는 라벨=1 채널에만 값이 있음).
- **로지스틱은?** 계수 × 표준화 값으로 같은 방식의 기여도를 계산했고, 그룹별 비중이 HGB와 거의 같아(08-25 라벨 33%, 과거 수준 23%) 그림은 HGB로 대표했다.
- **읽는 법**: 과거 중앙값↑ → Rising↓ (평균회귀) · 08-25 라벨=1 기준선↑ → Rising↑ (라벨 1을 받으려고 넘어야 했던 기준이 높았다 = 9월 초 영상이 그만큼 잘 나왔다는 역추론) · 변동성·쇼츠 성과↑ → Rising↑ · 최근 28일 롱폼 수↑ → Rising↓

### ③ 개별 예측 사례 — `fig3_local_example.png`
- **어떤 채널**: 08-25 라벨=0인데 submit_38 상위 139개(상위 20%)에 든 채널 중 가장 높은 채널 (121위).
- **순위 비교**: 08-25 규칙만 쓰면 164위, 모델(submit_21)은 83위 → 둘을 섞어 121위.
- **SHAP 막대**: s2 구조 모델 기준. 조회수 변동성 +0.73, 쇼츠 성과 +0.71, 낮은 과거 중앙값 +0.63이 끌어올림.

### 아래 박스
- **51%**: submit_38 순위를 08-25 라벨 그룹(1 / 0 / 없음) 평균으로만 대체했을 때 설명되는 순위 변동 비율 (R²).
- **127개**: submit_38 상위 139개 중 08-25 라벨=1인 채널 수 (라벨=0 5개, 라벨 없음 7개; 전체 라벨=1 채널은 134개).

## 발표·질의응답용 문구

- SHAP: 「최종 앙상블을 구성하는 HGB 모델을 대표로 SHAP 분석했습니다.」
- 「최종 모델 해석이 맞나요?」 → 「최종 제출은 모델 순위와 08-25 라벨 규칙을 반반 섞은 것입니다. 규칙 쪽은 규칙 자체가 해석이고, 모델 쪽은 구성 모델을 같은 설정으로 다시 학습해 해석했습니다(제출 파일과 순위상관 0.994). 최종 제출 파일은 아래 박스처럼 직접 분해했습니다.」
