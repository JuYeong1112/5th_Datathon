# EPOCH 제5회 데이터톤: YouTube Rising Channel Prediction

데이터 사이언스 연합 동아리 EPOCH 제5회 데이터톤 참가 프로젝트입니다. 기준일 현재 이용 가능한 정보로 채널의 이후 성장 여부를 예측합니다.

## 문제 정의

예측 단위는 `채널 × 기준일`이며, 각 행에 해당 채널이 성장 국면(Rising)에 들어갈 확률을 예측합니다. Rising은 채널의 절대 규모가 아니라 과거 성과 대비 성장세를 기준으로 정의합니다.

라벨은 롱폼 영상만 사용해 다음과 같이 계산합니다.

1. 영상별 `view_5d`: 업로드 후 108~132시간 구간 스냅샷 조회수의 최댓값
2. `past_score`: 기준일 이전에 업로드된 롱폼 영상의 `view_5d` 중앙값
3. `future_score`: 기준일 이후에 업로드된 롱폼 영상의 `view_5d` 중앙값. 영상이 없으면 0
4. `growth_score = log1p(future_score) - log1p(past_score)`
5. 같은 기준일의 `growth_score` 상위 20%를 Rising(label=1)으로 지정

표본에는 기준일 이전 `view_5d`가 있는 롱폼 영상이 3편 이상이고 `past_score >= 100`인 채널만 포함합니다. 쇼츠는 라벨 계산에서 제외합니다.

## 시간 기준 검증

데이터에는 학습 라벨 기준일 두 개가 있습니다. 같은 채널이 여러 기준일에 등장할 수 있으므로 랜덤 행 분할은 사용하지 않습니다.

| 구분 | 기준일 | 사용 원칙 |
| --- | --- | --- |
| Train | 2026-08-11 | 학습 및 EDA에 사용 |
| Holdout | 2026-08-25 | 4주차 최종 평가 전까지 열람 및 튜닝에 사용하지 않음 |
| 본선 예측 | 2026-09-01 | `sample_submission.csv`의 예측 대상 |

주요 검증은 2026-08-11로 학습하고 2026-08-25로 평가하는 시간 순서 분할입니다. 주 지표는 PR-AUC, 보조 지표는 ROC-AUC입니다. 피처는 `make_features(D)`처럼 기준일을 입력받아 계산하고, 해당 기준일 이후의 정보가 섞이지 않도록 합니다.

제출 대상은 694행이므로 리더보드 점수는 약 ±0.03 변동할 수 있습니다. 0.01 수준의 점수 차이만으로 모델을 선택하지 않고 로컬 시간 기준 검증 결과를 우선합니다.

## 진행 순서

1. 문제와 데이터를 확인하고 날짜 기준 Train/Holdout을 분리합니다. EDA는 Train 데이터만 사용합니다.
2. 전처리와 기준일 시점 피처를 만들고 베이스라인 및 연습 제출 결과를 기록합니다.
3. 모델과 시간 기준 검증 결과(PR-AUC, ROC-AUC)를 비교합니다.
4. 튜닝 후 Holdout을 한 번 평가하고, 최종 노트북과 제출 파일을 정리합니다.
